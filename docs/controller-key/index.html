Generate an encrypted controller key or sign an exact Server challenge on this device. This page makes no network requests and stores nothing in the browser.

1. Generate a controller key

Do this once on a controller-controlled device. Download both files and preserve the encrypted private package separately from the public package.

Use at least 16 characters. A lost passphrase cannot be recovered. Never upload the encrypted private package to a Server or evidence repository.
